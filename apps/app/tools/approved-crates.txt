# The crates that may be in the desktop and phone shell (every package in apps/app/src-tauri/Cargo.lock, by name).
#
# A crate that is not listed here fails the no-network guard (apps/app/tools/check-no-network-deps.mjs, and the tests), so a new
# dependency, direct or indirect, needs a human to read this file in the review and decide it is not a way to reach the network.
# Dependabot updates change versions, not names, and pass. A new name does not.
#
# Do not add a crate here to make a build pass until you know what it does: an HTTP, TLS, DNS, socket, WebSocket, QUIC or
# download crate (for example minreq, socket2, mio, async-io, nyquest) is exactly what this list exists to stop. The banned
# list in check-no-network-deps.mjs is a second, separate check for the best-known ones.
#
# After a deliberate dependency change, regenerate with: node apps/app/tools/check-no-network-deps.mjs --list-crates
# and read the diff before committing it.
